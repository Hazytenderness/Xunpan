# 数据格式

## batches/<日期>/batch.json

```json
{
  "批次": "2026-10-05",
  "来源": ["ataous-site@98b41d9:data/suppliers/2026-10-01-batch300.json"],
  "筛选口径": "站点状态=询价中",
  "款数": 0,
  "店铺数": 0,
  "询盘条数": 0
}
```

## batches/<日期>/queue.json

一条 = 一家店 × 一款（同店多款时 `合并到` 指向主条，只发主条）。

```json
{
  "id": "B0H32XFZ43-761713110567",
  "asin": "B0H32XFZ43",
  "产品": "湿巾盒（带密封盖）",
  "关键规格": "约 20×12×8 cm，带弹盖",
  "我方参考包装": "25×20×15 cm / 500 g",
  "offerId": "761713110567",
  "商品链接": "https://detail.1688.com/offer/761713110567.html",
  "站点记的供应商": "上海欣略实业有限公司",
  "页面卖家": null,
  "旺旺名": null,
  "候选排名": 1,
  "参考价": 179,
  "合并到": null,
  "话术类型": "A",
  "r1_text": "…",
  "r2_text": null,
  "状态": "待发R1",
  "备注": ""
}
```

`页面卖家`、`旺旺名` 由本地发送端打开商品页后填写；和 `站点记的供应商` 不一致时以页面为准。

## batches/<日期>/sent_log.jsonl

```json
{"id": "...", "轮次": "R1", "时间": "2026-10-06T10:12:03+08:00", "文本": "...", "核对": {"收件人": true, "内容一致": true, "未误发": true}, "发后新增条数": 1, "结果": "成功"}
```

## batches/<日期>/chats/<offerId>.json

```json
{"offerId": "...", "旺旺名": "...", "读取时间": "...", "消息": [{"时间": "...", "发送方": "我方|对方|系统", "类型": "文本|图片|视频|卡片", "内容": "...", "文件": "media/<offerId>/xxx.jpg"}]}
```

`发送方=系统` 的（自动欢迎语、促销推送、评价邀请）不算回复。

## batches/<日期>/quotes.jsonl

每家一行，每个字段都是 `{值, 原话, 时间}`，没回答的为 `null`。

```json
{
  "id": "...",
  "状态": "已回",
  "是否同款": {"值": "是", "原话": "有的亲", "时间": "..."},
  "现货": null,
  "阶梯价": {"值": {"300": null, "500": 6.8, "1000": 6.2}, "原话": "500个6.8，1000个6.2", "时间": "..."},
  "起订量": null,
  "产品尺寸净重": null,
  "包装尺寸毛重": null,
  "箱规": null,
  "中性包装": null,
  "定制": null,
  "打样": null,
  "交期": null,
  "开票点数": null,
  "图片": ["media/.../1.jpg"],
  "视频": [],
  "缺项": ["起订量", "箱规", "中性包装"]
}
```
