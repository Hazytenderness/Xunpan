# 询盘话术

## 写法规则

- 像真人随口问：口语、短句、不编号、不说「麻烦帮忙确认以下事项」这类公文腔。
- 第一轮不超过 4 行，只问 3 件事：**货对不对／有没有现货、500 个什么价和起订量、实拍图**。
- 第二轮只问上一轮没拿到的，一次最多 3 项。
- 必须带上这款的**关键规格**（站点里的规格，或 Amazon 对标款的关键参数），让对方报对 SKU。页面上有多个规格的，点名要哪个。
- 不说「我们做日本亚马逊」以外的背景；不压价，不承诺下单。
- 每条话术写完对照一遍：对方能不能 10 秒内回完？回不完就再砍。

## 第一轮（R1）

**A. 页面上就有我们要的规格**

```text
老板你好，这款{规格}有现货吗？
拿500个大概什么价，起订量多少？
方便的话发几张实拍图看看，谢谢~
```

**B. 页面上规格不完全对（需要定做／改规格）**

```text
你好，这款能做{我们要的规格}吗？
能做的话500个大概什么价，起订多少？
```

**C. 以图搜图匹配的，不确定是不是同款**

```text
你好，请问有这种{一句话描述关键特征}的款吗？
有的话发个链接或实拍图看看~
```

**D. 同一个店铺有多款**

```text
老板你好，你家这几款想一起拿：
{款1 规格}、{款2 规格}
各拿500个大概什么价，起订多少？有实拍图发几张~
```

## 第二轮（R2，按缺项拼）

从下面挑缺的项，最多 3 个，拼成一条：

| 缺项 | 问法 |
|---|---|
| 包装尺寸、重量 | 单个包装多大、多重？ |
| 箱规 | 一箱装几个，外箱多大多重？ |
| 中性包装 | 能发中性包装吗，不要带牌子和中文的那种 |
| 定制 | 印logo、做彩盒的话多少个起？ |
| 打样 | 能先拿个样吗，样品费多少，几天能发？ |
| 交期 | 500个下单后几天能发货？ |
| 开票 | 开票的话加几个点？ |
| 视频 | 有实拍视频的话也发一个~ |
| 产品尺寸 | 产品本身尺寸和净重是多少？ |

示例：

```text
好的谢谢！再问下：一箱装几个、外箱多大多重？
能发中性包装吗？开票加几个点？
```

## 催回（48 小时没回）

```text
老板在吗？上面那款500个的价方便报一下吗~
```

只催一次，再不回标「未回」，不再发。
