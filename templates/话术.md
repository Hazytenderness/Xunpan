# 询盘话术

## 写法规则

- 第一轮用下面两版模板，**表达方式是你定的，不改**，只替换产品名。
- 产品名必须带上对标款的**关键规格**，让对方报对规格。
- 第二轮只问上一轮没拿到的，一次最多 3 项。
- 不压价，不承诺下单。

## 第一轮（R1）· 你定的两版，原话不改，只替换 {产品}

**A 版 · 简版**

```text
{产品}有现货吗？起订多少，产品包装尺寸多少，包装的图片可以发下
```

**B 版 · 详版**

```text
{产品}，现货有没有，单品包装尺寸多少、外箱装箱一箱有几件，能不能发中性包装，有实拍图和视频的话发一下，谢谢
```

- {产品} 用中文写清对标款的关键规格，例如「40cm白色防滑无痕衣架」
- 同一家店有两个链接的，{产品} 写成「X和Y」
- 不加开头问候，不改句式和标点

## 第二轮（R2，按缺项拼）

从下面挑缺的项，最多 3 个，拼成一条：

| 缺项 | 问法 |
|---|---|
| 包装尺寸、重量 | 单个包装多大、多重？ |
| 箱规 | 一箱装几个，外箱多大多重？ |
| 中性包装 | 能发中性包装吗，不要带牌子和中文的那种 |
| 定制 | 印logo、做彩盒的话多少个起？ |
| 打样 | 能先拿个样吗，样品费多少，几天能发？ |
| 交期 | 500个下单后几天能发货？ |
| 开票 | 开票的话加几个点？ |
| 视频 | 有实拍视频的话也发一个~ |
| 产品尺寸 | 产品本身尺寸和净重是多少？ |

示例：

```text
好的谢谢！再问下：一箱装几个、外箱多大多重？
能发中性包装吗？开票加几个点？
```

## 催回（48 小时没回）

```text
老板在吗？上面那款500个的价方便报一下吗~
```

只催一次，再不回标「未回」，不再发。
