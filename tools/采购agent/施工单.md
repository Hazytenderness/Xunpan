### 判定顺序（逐条照做）
1. 事实只留 `候选 == 候选.offerId` 的；`人工.已填` 里有的项整条替换同项事实。
2. 逐项判核心缺项、辅助缺项，同时给每个缺项定「问句键」：
   - 匹配确认：完全匹配算有；不匹配 → 资料状态=不匹配结束、动作=完成，直接出；类似款 → 交人工加「只有类似款，接不接受替代你定」，动作=待你决策。
   - 定制款=true：定制起订量没数 → 键 `定制起订量`；单位与销售单位不可比 → `定制起订量.单位不明`；数量 > rules.定制起订上限 → 键 `类似现货`；≤ 上限 → 起订量算有。
   - 采购单价：没值 → `采购单价`；单位等于计数 → 折算单价＝原价；单位在单件量词里且计数=套且件数是正整数 → 折算单价＝原价×件数，折算=true；其余（含不明）→ `采购单价.单位不明`。
   - 起订量：没值 → `起订量`；单位等于计数，或计数=个且单位在单件量词里 → 算有；否则 `起订量.单位不明`。
   - 包装：没有 → 包装尺寸、带包装重量都缺，键各自同名；口径=产品 → 当没有；口径=不明 → 两项都缺，只出一个键 `包装尺寸.口径不明`；对应单位=不明，或对应单位=单个而计数=套 → `包装尺寸.对应不明`；单位明确=false → `包装尺寸.单位不明`。否则长宽高都>0 算包装尺寸有，重量克>0 算带包装重量有。
   - 包装方式有非空值算有；贴标 能贴/不能贴 算有，不能贴 → 交人工加「不能贴标」。
   - 辅助项：中性包装 能/不能、每箱数量>0、实拍图/视频 已发/不能提供 算有；在「无法提供」里也算有。
3. 能问：不在「无法提供」里，且 `已问次数[键的点号前部分] < rules.每项最多问次数`。
4. 抽取.待决策非空 → 并进交人工，动作=待你决策。
5. 先后拦截（命中即停，下一句空）：人工.暂停 → 人工暂停；最后发送.结果=未知 → 核回执；已是待你决策 → 待你决策。
6. 最新消息方=我方：核心有缺、最后发送成功、距今 ≥ rules.无回复收口小时 → 资料未齐已收口、动作=完成；否则 等商家回复。
7. 最新消息方=无 且 已问次数为空：用「首轮」模板，关键规格为空就报错退出；这次问=[匹配确认, 包装尺寸, 带包装重量]。
8. 挑问题：匹配确认缺 → 只问它，问不了就资料未齐已收口。否则按 定制 → 采购单价 → 起订量 → 包装尺寸 → 带包装重量 → 包装方式 → 贴标 取前 rules.每条最多问题数 个能问的；两个都是 rules.合并问句 里的一对且键都不带点号 → 用合并句；同一键只出一次。核心有缺但一个都问不了 → 资料未齐已收口、动作=完成。
9. 核心齐 → 资料状态=核心资料齐全；按辅助项顺序同样取能问的，取不到 → 动作=完成。
10. 商家反问按 rules.反问回答 生成，拼在问句前面；只有反问回答也算发送。
11. 这次问 记「键的点号前部分」，去重，按出现顺序。模板里 {销售单位}=叫法、{计数}=计数、{关键规格}=关键规格。

### 判定顺序
1. 把「现在」换成北京时间。星期几（周一=1）不在 rules.调度.工作日里，或 现在 ≥ 当天结束 → 可发送=false、原因=「不在发送时间」，计划、新绑定为空，停的号、要你做照下面第 3 步照常出，等待为空，直接出。
2. 窗口：开始 = max(现在, 当天开始时刻)；截止 = min(现在 + 窗口分钟, 当天结束时刻)。开始 ≥ 截止 → 同第 1 步，原因=「不在发送时间」。
3. 停的号：名单里 状态≠正常 → 原因＝「账号.json 标暂停：{备注}」（备注空就只写「账号.json 标暂停」）；状态正常但 风控 非空 → 原因＝「风控：{风控}」。每个停的号在要你做里加一句「{代号} 被拦（{原因}），去验证后把 账号.json 里的状态改成正常」。全部号都停 → 可发送=false、原因=「三个号都停了」（按名单实际个数写「全部 N 个号都停了」），计划为空，队列每条进等待、原因「{绑定号}暂停」或「没有可用的号」，直接出。
4. 间隔：间隔秒(代号, t) = 间隔最短秒 + int(sha256("{代号}|{t 按上面格式}").hexdigest(), 16) % (间隔最长秒 − 间隔最短秒 + 1)。
5. 每个能用的号排时刻：第一个 = 最后发送为空 ? 开始 : max(开始, 最后发送 + 间隔秒(代号, 最后发送))；之后每个 = 上一个 + 间隔秒(代号, 上一个)；只留 < 截止 的。
6. 队列整理：同一供应商只留第一次出现的；按 倍数 从高到低排，倍数为 null 排最后，同倍数保持原顺序。
7. 等待（先出，不占时刻）：绑定账号是停的号 → 原因「{代号}暂停」；绑定账号不在名单 → 原因「绑定账号不在名单」。
8. 填时刻：所有号的时刻一起按（时间，今日已发，代号）排序，逐个填：先取绑定在这个号的第一条；没有就取第一条没绑定的，并记进新绑定；都没有这个时刻就空着，不出。
9. 填完还剩的：原因「本轮排不下」进等待。计划按时间、再按账号排。
